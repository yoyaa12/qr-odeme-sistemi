Test etmek istediğiniz paneli aşağıdaki kartlardan seçerek açabilirsiniz:

📱 Müşteri QR Menü

Müşterinin masadaki QR kodunu okuttuğunda karşılaştığı ekran. Ürün seçimi, pizza boyutları, ekstra tatlı sosları, malzeme çıkarma ve simüle ödeme yapılabilir.

🪑 Masa 1 QR Menüsü Aç 🪑 Masa 2 QR Menüsü Aç

👨‍🍳 Mutfak Paneli

Müşteri ödemeyi tamamladığı an siparişler sayfa yenilenmeden sesli ve canlı uyarı ile bu ekrana düşer. Hazırlanıyor / Hazır durum güncellenir.

🔥 Mutfak Paneline Git

🛎️ Garson Paneli

Mutfakta "Hazır" yapılan siparişler canlı olarak garson paneline yeşil renkte düşer. Garson siparişi masaya teslim eder.

🚀 Garson Paneline Git

⚙️ Yönetici Paneli

Kategoriler (Çorbalar, Ana Yemekler, Tatlılar, İçecekler), Ürünler, Fiyatlar ve Masaların yönetildiği admin arayüzü.

⚙️ Admin Paneline Git

💳 Kasa Paneli

Masaların aktif adisyonlarını ve kasada tahsilat bekleyen hesapları görüp masayı kapatabileceğiniz özel kasa ekranı.

💰 Kasa Paneline Git
